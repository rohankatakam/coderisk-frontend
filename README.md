# CodeRisk Frontend

The public landing page for [CodeRisk](https://github.com/rohankatakam/coderisk), an evidence-based code-change risk prototype.

The website reflects the repository's current source-built workflow. CodeRisk does not yet publish a pip package, Homebrew formula, binary release, hosted cloud product, or Slack integration.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run build
```

The site is built with Next.js, React, TypeScript, and Tailwind CSS and is deployed separately from the Go repository.
